# Source ranking

Every source in `src/data/sources.json` is scored by hand from 0 to 5 on six criteria, with a written reason for each score in the source's `ranking` field. The overall score (0 to 100) is computed in `src/lib/ranking.ts`: each score is divided by 5 and multiplied by the criterion's weight. Ties sort by access score, then id. The `rank_sources` tool returns the same order with every reason.

The ranking answers one question: how useful is this source to this server for assessing a piece of information, today? It is not a judgment of the organization's work. A high-quality provider that requires a commercial contract ranks low on access and therefore lower overall.

## Criteria

| Criterion | Weight | Question | Scale |
|---|---|---|---|
| Access | 25 | Can this server query it without a contract? | 5 keyless public; 4 free key, self-serve; 3 paid key, self-serve; 2 approval or request only; 1 commercial contract; 0 self-host only or no shared data |
| Relevance | 20 | How directly does it help assess a piece of information? | 5 itemized fact-checks or verdicts; 4 itemized analysis of narratives, actors or media; 3 indirect evidence (registries, datasets); 2 monitoring data needing analysis; 1 tangential; 0 not information-integrity data |
| Evidence | 20 | How strong and transparent is the method behind each item? | 5 human editorial review with published method and sources (IFCN/EFCSN signatory or official record); 4 documented human or hybrid method; 3 automated model with published evaluation; 2 proprietary method, little disclosure; 1 unclear; 0 none |
| Freshness | 10 | How current is the data? | 5 real-time or daily; 4 weekly; 3 monthly; 2 irregular; 1 stale (over a year); 0 unknown |
| Rights | 15 | What may we do with what it returns? | 5 open licence (e.g. CC BY); 4 headline, link and excerpt use customary (public feed); 3 API terms allow display without redistribution; 2 customer terms only; 1 unconfirmed; 0 reuse prohibited |
| Reliability | 10 | How sure are we the interface works as documented? | 5 live-tested here; 4 public schema verified against primary docs; 3 documented; 2 advertised, not public; 1 undocumented; 0 no interface |

## Notes

- The fact-checkers' feeds rank highest because they are keyless, editorially reviewed and current. A feed covers only the provider's latest items, not its archive.
- Cofacts has the best per-item data of any source (structured replies, open licence) but needs an app id issued on request, so access is 2.
- Detection services (Reality Defender, AI or Not, Pangram, Deep Media) score 2 on evidence because their models are proprietary; their scores are model output, not editorial findings.
- EDMO's archive is strong editorially but has no machine interface (access 0, reliability 0); it is listed so routing can point people to it.
- PolitiFact publishes a feed but its terms forbid redisplaying its content, so it is not in the registry.
